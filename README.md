TransitBee - MERN Stack Movers & Packers Booking Platform

TransitBee is a full-stack web application that connects customers with verified movers and packers through a seamless booking and payment experience. The platform supports real-time communication, provider filtering, dynamic pricing logic, and secure payments.

✨ Features ✨

 User Module
  1. Guest search (pickup, drop-off, date)
  2. Provider filtering based on availability & service area
  3. Distance-based cost estimation
  4. Booking request system
  5. Stripe secure payment integration
  6. Booking history & status tracking
  7. Real-time chat with provider

Provider Module
  1.  Accept / Reject booking requests
  2.  Manage job status (Pending → Accepted → In-progress → Completed)
  3.  Upload KYC documents
  4.  View earnings & service history

Admin Module
  1.  Manage users & providers
  2.  Area management
  3.  Booking monitoring
  4.  Platform-level control
